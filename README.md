# FNP Sales Analysis – Excel Dashboard

## 📊 Project Overview

**FNP Sales Analysis** is an interactive **Microsoft Excel Data Analytics project** built to analyze sales performance, customer spending, order delivery time, product categories, occasions, cities, months, and order-time patterns.

The dashboard converts raw sales data into meaningful business insights using **Excel Pivot Tables, Pivot Charts, Slicers, and KPI cards**.

This project is designed as a portfolio project for demonstrating practical **Data Analyst / Business Analyst skills**.

---

## 🎯 Business Problem

FNP (Ferns N Petals) receives orders across different occasions, product categories, cities, months, and times of the day.

The objective of this project is to answer questions such as:

- How much total revenue was generated?
- How many orders were placed?
- Which occasions generate the highest revenue?
- Which product categories contribute the most revenue?
- Which months have the highest and lowest sales?
- Which cities have the highest number of orders?
- Which products generate the highest revenue?
- At what hours are orders most frequently associated with higher revenue?
- What is the average customer spending?
- What is the average order delivery time?

### 3. Revenue by Months

Shows monthly revenue trends from January to December.

The dashboard includes products such as:

- Imphal

## 🧹 Data Analysis Process

The project follows a typical Data Analyst workflow:

### Step 1 – Data Collection
Collected the FNP sales dataset containing order, product, customer, date, location, category, occasion, and delivery-related information.

### Step 2 – Data Cleaning
Checked the dataset for:

- Missing values
- Duplicate records
- Incorrect data types
- Date formatting issues
- Inconsistent categorical values
- Numerical formatting

### Step 3 – Data Preparation
Prepared fields required for analysis, including:

- Order Date
- Delivery Date
- Month
- Hour
- Occasion
- Category
- City
- Revenue
- Delivery Time

### Step 4 – Data Analysis
Created Pivot Tables to calculate:

- Total Orders
- Total Revenue
- Average Customer Spend
- Average Delivery Time
- Revenue by Occasion
- Revenue by Category
- Revenue by Month
- Orders by City
- Revenue by Hour
- Top 5 Revenue-Generating Products

### Step 5 – Dashboard Development
Converted the analysis into an interactive Excel dashboard using charts, KPI cards, slicers, and filters.
